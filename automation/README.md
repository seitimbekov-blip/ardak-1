# Автоматизация заливки на Портал закупок

## exclude_lots.py — исключение лотов (не-ЭМ)

Автоматизирует действие «Исключить» для обычных лотов (ОТ, ЗЦП, ОИ и т.д.,
не ЭМ) на Портале закупок Фонда, на основе рабочего `em_agent.py` (для ЭМ)
и инструкции по исключению лота.

### Установка браузера Playwright (один раз)

```bash
pip install -r requirements.txt
playwright install chromium
```

### Запуск — сначала обязательно сухой прогон (dry-run)

```bash
python automation/exclude_lots.py путь/к/файлу_заливки.xlsx
```

По умолчанию скрипт **ничего не меняет на портале**: доходит до диалога
подтверждения исключения, вводит причину, делает скриншот диалога в
`automation/screenshots/` и закрывает диалог (Escape), не нажимая красную
кнопку «Исключить». В конце — сводка: сколько лотов обработано в
сухом прогоне, сколько ошибок.

Проверьте скриншоты и лог перед реальным запуском.

### Реальное исключение (после проверки dry-run)

```bash
python automation/exclude_lots.py путь/к/файлу_заливки.xlsx --live
```

Перед началом попросит явное подтверждение («Введите 'да'»). Рекомендуется
сначала потренироваться на неактуальном плане закупок (например, ПЗ-2025
года), прежде чем запускать на текущем боевом плане.

### Как это работает

1. Открывает браузер, просит вручную войти на портал и перейти на страницу
   «Пункты плана» нужного года (логин/2FA не автоматизируется - это должен
   делать человек).
2. Для каждой строки файла со статусом «исключить»:
   - ищет лот по номеру из колонки «№» (номер лота в ИСЭЗ/Портале);
   - Действия → Исключить;
   - вводит причину (если колонка «Причина исключения» пуста - подставляет
     стандартную «в связи с корректировкой бюджета»);
   - в dry-run - скриншот и отмена; в `--live` - нажимает подтверждение.
3. Если по лоту происходит ошибка - делает скриншот `error_N.png`,
   записывает лот в список ошибок и переходит к следующему (не
   останавливает весь процесс), как и просил Ардак.
4. В конце выводит сводку и список лотов с ошибками - по каждому нужно
   вручную решить: скорректировать данные или окончательно исключить лот
   из заливки.

### Известные ограничения / что стоит проверить перед боевым запуском

- Селекторы полей на странице поиска (`input[placeholder*='Номер пункта
  плана']`, кнопка «Найти», «Действия», «Исключить») взяты из рабочего
  `em_agent.py` для лотов ЭМ - для обычных лотов страница поиска должна
  быть той же, но стоит свериться визуально при первом dry-run.
- Фильтр «Способ закупки» на странице поиска для обычных лотов **не**
  выставляется (в отличие от ЭМ, где всегда выбирается «Электронный
  магазин») - поиск идёт по номеру лота без фильтра по способу закупки.
